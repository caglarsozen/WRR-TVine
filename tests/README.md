# Software checks

Run these scripts from the repository root.

| Script | Scope |
|---|---|
| `test_invariants.R` | Base R checks of weights, causal information sets, ties, deterministic random streams, scoring identities and checkpoint recovery |
| `test_vine_interface.R` | Weighted pair-copula estimation, family pools and predictive mixtures |
| `test_garch.R` | Synthetic fixed-parameter filtering, inverse distributions and future-perturbation checks |
| `test_integration.R` | Synthetic end-to-end estimation, simulated forecasts and checkpoint reuse |

The invariants test requires no third-party R package. The other scripts require the relevant estimation dependencies. The synthetic tests check implementation properties, not the accuracy of financial forecasts.

## Verification of the reference results

The repository's read-only result audit was run against the completed reference archive: 1,705 consistency checks passed, all six universe/specification cases passed the separate base R verification, and all 14 reference tables matched the regenerated summaries. The 21 table sources and five figures can be regenerated by the reporting utilities.

The 25 base R invariant checks also passed. The package-dependent synthetic scripts are supplied for execution in a complete R environment. These checks do not claim a second full estimation of the reference experiment.
